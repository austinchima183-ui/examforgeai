     4→/// source of truth. Using constants instead of raw strings prevents
     5→/// typos, makes refactoring safe, and enables IDE autocomplete.

     7→/// ```dart
     8→/// context.go(RouteNames.dashboard);
     9→/// GoRouter.of(context).goNamed(RouteNames.login);
    10→/// ```

    12→/// Convention: all paths are lowercase with hyphens for multi-word
    13→/// segments (kebab-case), matching common web URL conventions.
